Known beta limitations

The macOS plugin declares a factory preset without a name. This may appear as a blank entry in your DAW’s preset list. This issue belongs to the original plugin binary and remains in this beta. The plugin’s DSP supports 32-bit floating-point processing; 64-bit audio processing is not supported.

Installer payloads were checked. The Windows installer still needs an installation and DAW test on a real Windows x64 machine.

My DAW cannot find YOURDRUM.

Confirm the OS requirements, enable VST3 scanning and rescan the standard folder. YOURDRUM is an instrument: add it to an instrument or MIDI track. On Windows, confirm that Microsoft Visual C++ x64 runtime installed successfully. The macOS build requires 15.2 or newer.

Can I install the plugin manually?

Choose “Manual VST3 ZIP” on the download card, extract the archive and copy the complete YourDrum.vst3 bundle to the folder above. On Windows, the Microsoft Visual C++ x64 runtime is still required. Then rescan plugins in your DAW.

How do I remove YOURDRUM?

Close your DAW. On Windows, use Settings → Apps → YOURDRUM → Uninstall. On macOS, move YourDrum.vst3 from the installation folder to the Trash. Your own samples and projects stay in their original folders.

Why do the original ZIP names show an older version?

The downloads were retrieved from the official beta directory. Both plugin binaries report version 1.0.0. The Windows source archive is named YourDrum0.1.0Win.zip, and the macOS source is YourDrum-0.1.1OSX.zip. The binaries are unchanged; the installers and distribution packaging are new.
