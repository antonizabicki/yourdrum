YOURDRUM beta distribution

Open index.html directly or serve this directory over HTTP.
The website contains actual installers, normalized manual VST3 ZIPs, sizes and SHA-256 checksums.
Source of download metadata: beta-downloads.json.
After changing this JSON, regenerate assets/beta-data.js with:
python3 tools/sync-downloads.py

macOS minimum: 15.2. Apple Silicon and Intel are included.
Windows minimum: Windows 10/11 x64. Microsoft Visual C++ x64 runtime is bundled with Setup.
Packages are unsigned. macOS is not notarized. Signing and real Windows/DAW testing remain before a production release.
